## Tips for Adding Your Own Products

1. **ProductID**: Use a consistent format (PROD001, PROD002, etc.)
2. **KeyBenefit**: Focus on the main problem it solves or benefit it provides
3. **TopFeatures**: List 3-5 concrete features separated by semicolons
4. **Keywords**: Include 8-15 relevant search terms
5. **Priority**: Use 5 for proven winners, 3-4 for good products, 1-2 for testing
6. **Status**: Start with READY, script will change to USED
7. **Affiliate URL**: Always use your Amazon Associate tag

## Finding Products

- **Amazon Best Sellers**: Browse category best sellers
- **Amazon Movers & Shakers**: Products with biggest sales rank gains
- **Your own purchases**: Products you actually use and recommend
- **Seasonal trends**: Holiday gifts, back-to-school, summer items
- **Problem-solving**: Think about common problems people search for

## Compliance Reminders

- ✅ Always include disclosure in DisclosureLine column
- ✅ Don't make medical claims
- ✅ Don't guarantee results
- ✅ Be honest about product features
- ✅ Only recommend products you'd actually use
