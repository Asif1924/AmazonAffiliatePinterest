# Google Sheets Setup Guide

## Step 1: Create a New Google Sheet

1. Go to [Google Sheets](https://sheets.google.com)
2. Create a new spreadsheet
3. Name it: "Amazon Affiliate Pinterest Products"

## Step 2: Create the "Products" Worksheet

### Column Headers (Row 1)

Create these exact column headers in row 1:

| Column | Header | Description |
|--------|--------|-------------|
| A | ProductID | Unique identifier (e.g., PROD001) |
| B | Niche | electronics \| home/kitchen \| tools \| fitness \| cars \| computer accessories |
| C | ProductName | Full product name |
| D | Brand | Product brand |
| E | KeyBenefit | One short sentence describing main benefit |
| F | TopFeatures | 3-5 features separated by semicolons (;) |
| G | IdealFor | Target audience or use case |
| H | Keywords | 8-15 keywords separated by commas (,) |
| I | PriceBand | budget \| mid \| premium |
| J | AmazonAffiliateURL | Your Amazon Associate link |
| K | DisclosureLine | Compliance text (same for all rows) |
| L | Angle | Problem/Solution \| Upgrade \| Gift \| Comparison \| Quick Tip |
| M | HookStyle | Question \| Bold Claim \| "Stop Doing This" \| "3 Things" \| "Best For" |
| N | TemplateID | T1, T2, T3, T4, or T5 |
| O | BackgroundTheme | clean \| tech \| kitchen \| gym \| garage \| car |
| P | Status | READY \| USED \| PAUSED |
| Q | LastUsedDate | YYYY-MM-DD format |
| R | Priority | 1-5 (5 = highest priority) |
| S | PinTitle | Auto-generated by formula |
| T | PinHookOverlay | Auto-generated by formula |
| U | PinDescription | Auto-generated by formula |
| V | BoardName | Auto-generated by formula |
| W | CanvaImageName | Auto-generated by formula |

### Formulas to Add

**Cell K2** (then copy down for all rows):
```
As an Amazon Associate I earn from qualifying purchases. #ad
```

**Cell S2** - Pin Title Formula (copy down):
```
=IF(C2="","",C2 & " — " & IF(L2="Upgrade","Easy upgrade for ","Best pick for ") & G2)
```

**Cell T2** - Pin Hook Overlay Formula (copy down):
```
=IF(C2="","",IF(M2="Question","Still dealing with " & LOWER(REGEXREPLACE(SPLIT(H2,",",TRUE,TRUE),"\s+$","")) & "?",IF(M2="Bold Claim","Fix this in 5 minutes",IF(M2="Stop Doing This","Stop struggling with this",IF(M2="3 Things","3 reasons you'll love this","Best pick for " & G2)))))
```

**Cell U2** - Pin Description Formula (copy down):
```
=IF(C2="","","Why it's worth it: " & E2 & " Features: " & SUBSTITUTE(F2,";"," • ") & ". Great for: " & G2 & ". Keywords: " & H2 & " " & K2)
```

**Cell V2** - Board Name Lookup Formula (copy down):
```
=IF(B2="","",IFERROR(VLOOKUP(B2,Boards!A:B,2,FALSE),"General Finds"))
```

**Cell W2** - Image Filename Formula (copy down):
```
=IF(A2="","",TEXT(TODAY(),"yyyy-mm-dd") & "_" & N2 & "_" & A2 & ".png")
```

## Step 5: Get Your Sheet ID

1. Look at your Google Sheet URL
2. It will look like: `https://docs.google.com/spreadsheets/d/SHEET_ID_HERE/edit`
3. Copy the `SHEET_ID_HERE` part
4. You'll need this for the Python script configuration

## Next Steps

After setting up your Google Sheet:

3. Configure the Python script with your Sheet ID
